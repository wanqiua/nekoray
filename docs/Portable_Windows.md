# NekoRay_BY_WanQiu 0.1

适用系统：Windows 10/11 x64，实际验收环境为 Windows 11。

解压整个文件夹后运行 **NekoRay_BY_WanQiu.exe**。首次启动选择默认优先内核，之后选中节点即可点击“自动 / Xray / sing-box”。自动模式在右侧按钮显示目标内核；不支持的选项可悬停查看原因。配置保存在程序目录的 `config` 文件夹。

内置 **Matsuri Xray 1.8.4 兼容版**、**sing-box 1.14.0**、Qt、TLS 和 VC++ 运行库。Xray 保留 `rc4-md5` 和原有 `allowInsecure` 设置，不包含 XHTTP 等后续功能。

## 0.1 的变化

- 修复 VLESS 订阅的 XUDP 参数导致 Xray 按钮不可用的问题。
- Hysteria2 支持订阅的证书 SHA-256 和跳端口别名。相同的 `ports`、`mport` 可同时出现；冲突范围仍会报错并保留原分组。
- 证书指纹可在 Hysteria2 高级设置中查看和编辑；即使开启跳过常规证书验证，也仍会检查已填写的指纹。
- “当前分组 → 删除不可用配置”识别有效的连接测试失败记录，优先采用 URL 结果；无可删项时显示说明。当前连接、未测试、过期或内核错误的配置不会被删除。
- 正常路由阻断不再刷出权限错误；内核选项保持单行，点击节点不会增高顶部区域。
- 产品名称和版本独立为 NekoRay_BY_WanQiu 0.1。

## 使用与升级

直接切换当前节点的内核会使已有连接重连。目标配置预检失败时保留当前连接，启动失败时尝试恢复原配置。对其他节点或批量设置内核只影响它们之后的连接。

批量 URL 测试默认并发 10，可在基本设置中调整。测速结果关联实际内核及配置；修改连接参数后需重新测试。订阅解析失败时仍保留原分组，避免误删已有节点。

从旧版升级时，先退出旧版并备份 `config`，再将其复制到新程序所在目录。无需重新导入节点、订阅或路由。良心云可在升级后重新更新订阅，补入之前因参数无法识别而未更新的节点。本包不包含个人配置。

Hysteria2 的证书 SHA-256 功能由随包 `nekobox_core.exe` 实现；官方 sing-box 没有等价的证书 DER 指纹字段，不要将该扩展替换成公钥指纹。外置 Hysteria2 使用原生 `pinSHA256` 参数。

GeoIP / Geosite 数据来自原上游便携包，旧上游自动更新已禁用。回退时使用原安装与配置备份，旧版不认识部分新增协议。
