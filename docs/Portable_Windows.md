# Nekoray 双内核便携版

适用系统：Windows 10 / 11，64 位。

解压整个文件夹后运行 `nekoray.exe`。首次启动选择默认优先内核，之后选中节点即可点击 **自动 / Xray / sing-box**。两核都支持的节点可手动切换，只有一核支持的配置自动使用该内核，界面会说明选择原因。配置保存在程序目录下的 `config` 文件夹。

本包以 Nekoray 3.26 为基础，包含 **Matsuri Xray v1.8.4 兼容版**、sing-box **v1.14.0**，以及配套 Qt、TLS 和 VC++ 运行库。Xray 固定到提交 `01208225ee7e508044cca8eb6776a117bcecd997`，支持 `rc4-md5` 和原有“跳过证书验证”选项（`allowInsecure`）。

兼容版 Xray 不包含 XHTTP 及后续版本新增的功能。跳过证书验证沿用节点原有设置，不会自动为所有节点开启。

此次改动：

- 当前节点可以直接切换内核，系统代理和 TUN 随连接切换；已有连接可能重连。目标配置预检失败时保留当前连接，启动失败时尝试恢复原配置。修改其他节点或批量设置内核只影响它们的下次连接。
- 批量 URL 测试并发执行，修正结果回写和配置相互影响的问题。默认并发 10，可在基本设置中调整为 1–64；导入旧配置时沿用原来的设置。
- 测试结果记录实际内核和配置；改动配置后的旧结果保留为历史。仅支持 UDP 的 Snell 节点显示 URL 测试“不适用”，不会因此被当作不可用节点删除。
- 新增 AnyTLS、Snell 4/6，使用 sing-box；支持导入、编辑、分享和订阅更新。Snell 链接必须明确版本；高级设置默认折叠，带有扩展参数的节点使用完整 Nekoray 分享链接保留字段。
- Hysteria2 新增 BBR 配置、Gecko 混淆、Chrome QUIC 指纹开关及随机跳端口间隔。旧参数继续保留，无法交给外置核心的新选项会显示原因。
- 订阅仅改名、重排或启用“更新前清空”时，唯一匹配的节点保留内核偏好和测试历史；订阅中有节点解析失败时保留原分组，避免部分失败误删节点。
- 主界面右键分组名可以新建、编辑、更新订阅或删除分组。
- 粘贴链接后直接点击操作按钮；选择“作为订阅（创建新组）”会打开新组编辑窗口，确认后才创建并更新。
- 分组类型使用“基本 / 订阅”单选按钮。

GeoIP / Geosite 数据库沿用官方 3.26 便携包中的版本。旧上游自动更新已禁用，以免覆盖本分支。

建议先在新目录试用。迁移原有配置前退出旧版并备份其 `config` 文件夹，再复制到本目录，无需重新导入节点或订阅。本包没有预置订阅或代理节点。需要回退时使用原安装和备份；原版 3.26 不识别本版新增协议。

真实系统代理、TUN 和 UAC 在 Windows 11 上验收；Windows 10 尚未实测。外置 TUN 同时启用 FakeIP、IP/CIDR 范围和 AsIs 域名策略时，会提示调整范围，避免域名还原后错误匹配；可改用进程范围。详细范围见 `docs/Dynamic_Core_Implementation.md`。

文件版本与 SHA-256 见 `core-versions.json` 和 `package-manifest.json`。与便携包同目录的 `*-source.zip` 包含此次修改后的源码及固定版本子模块；构建方法和兼容范围见 `docs`。
