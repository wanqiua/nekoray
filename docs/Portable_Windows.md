# Nekoray 双内核便携版

适用系统：Windows 10 / 11，64 位。

解压整个文件夹后运行 `nekoray.exe`。首次启动选择 **Xray** 或 **sing-box**，之后可在基本设置中切换。配置保存在程序目录下的 `config` 文件夹。

本包以 Nekoray 3.26 为基础，包含 **Matsuri Xray v1.8.4 兼容版**、sing-box **v1.14.0**，以及配套 Qt、TLS 和 VC++ 运行库。Xray 固定到提交 `01208225ee7e508044cca8eb6776a117bcecd997`，支持 `rc4-md5` 和原有“跳过证书验证”选项（`allowInsecure`）。

兼容版 Xray 不包含 XHTTP 及后续版本新增的功能。跳过证书验证沿用节点原有设置，不会自动为所有节点开启。

此次改动：

- 批量 URL 测试并发执行，修正结果回写和配置相互影响的问题。默认并发 10，可在基本设置中调整为 1–64；导入旧配置时沿用原来的设置。
- 主界面右键分组名可以新建、编辑、更新订阅或删除分组。
- 粘贴链接后直接点击操作按钮；选择“作为订阅（创建新组）”会打开新组编辑窗口，确认后才创建并更新。
- 分组类型使用“基本 / 订阅”单选按钮。

GeoIP / Geosite 数据库沿用官方 3.26 便携包中的版本。旧上游自动更新已禁用，以免覆盖本分支。

建议先在新目录试用。迁移原有配置前退出旧版并备份其 `config` 文件夹，再复制到本目录；更新现有便携目录时保留原 `config` 文件夹即可，无需重新导入节点或订阅。本包没有预置订阅或代理节点。

文件版本与 SHA-256 见 `core-versions.json` 和 `package-manifest.json`。与便携包同目录的 `*-source.zip` 包含此次修改后的源码及固定版本子模块；构建方法和兼容范围见 `docs`。
