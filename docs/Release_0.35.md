# NekoRay_BY_WanQiu 0.35

0.35 修复 sing-box 连接列表，并完善下方面板的展开 / 收起入口。历史 0.3 标签和发行文件保持原样。

## 连接列表

- 接通 sing-box 1.14.0 原生路由跟踪接口，通过现有 gRPC 显示 TCP / UDP 活动连接及最近 512 条关闭记录，无需开放额外的 HTTP 控制端口。
- 记录不受上游历史缓存的内存回收清理影响；正确区分入站监听地址、目标地址、路由改写与 FakeIP。
- 统计开关在启动节点时生效，启用后需重新连接。停止、切换内核或重连会清空旧实例记录，临时测速流量不会混入连接列表。
- 两个内核均在“首选项 > 基本设置”中启用连接统计；没有记录时显示中性的空态说明。

## 主界面

- 日志 / 连接标签栏右上角使用 20px 标准面板开关图标，无可见文字，点击区域为 44 × 32；常态透明无边框、无凸起效果，悬停时显示浅灰底。
- 标签栏改为统一的轻量样式，用主题强调色短下划线标识当前标签；面板图标随主题文字颜色调整。
- 收起只隐藏面板内容，保留标签栏和展开入口；展开时恢复原分隔高度。
- 调整按钮容器和标签栏高度，避免图标或点击区域被裁切。

## 版本与升级

产品版本、Windows 文件属性、内核产品标识及便携包名称同步为 0.35。内核上游版本仍为 wanqiua Xray 26.3.27-matsuri.1 与 sing-box 1.14.0。

便携包为 `NekoRay_BY_WanQiu-0.35-windows-x64.zip`，对应源码包为 `NekoRay_BY_WanQiu-0.35-windows-x64-source.zip`。退出旧程序并备份完整便携目录后，解压本包覆盖程序文件，保留原来的 `config`。启用连接统计后重新连接节点。

自动更新继续使用本仓库最新稳定发行版，备份旧程序目录、保留配置并重启。0.35 的便携包、对应源码及校验文件在本仓库 `v0.35` 发行页提供。

## 验证范围

连接跟踪测试覆盖真实回环 SOCKS TCP / UDP、活动与关闭状态、统计开关、Clash API 共存、内存回收、并发快照、有限历史和重连清理。GUI 回归覆盖真实核心进程到连接表格的链路、空态说明以及展开 / 收起和高度恢复。

未进行真实系统代理、TUN 或个人订阅验收。具体构建、测试和包校验结果见随包提供的 `NekoRay_BY_WanQiu-0.35-verification.md`。
