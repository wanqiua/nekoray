**使用方式**

| 操作 | 实现行为 |
| --- | --- |
| 选中一个节点 | 单行显示“自动 / Xray / sing-box”按钮；自动模式在按钮内显示目标内核，悬停可查看兼容性原因。自动模式先检查完整配置，再使用默认优先内核。 |
| 只有一个内核支持当前配置 | 使用支持的内核，禁用不适用的选择并说明原因；原手动偏好保留。 |
| 为当前运行节点点击选核按钮 | 预检目标配置，完成切换后更新实际运行状态；相同内核及相同有效配置不重启。既有连接可能重连。 |
| 为未运行节点选核，或在编辑窗口修改偏好 | 保存为下次连接的偏好。编辑窗口取消时不写入修改。 |
| 批量设置“下次连接内核” | 按节点能力处理并显示汇总；当前连接保持。 |
| 修改默认优先内核 | 影响自动模式下的后续连接，保存时不要求重启。 |
| “对比两个内核”或“测试另一内核” | 单独测试对应配置，保留节点偏好和当前连接。 |
| 目标配置无效或切换失败 | 预检不通过时保留当前连接；启动失败时尝试恢复原运行配置，恢复失败则明确显示已断开。 |

切换期间保留最新选择，旧请求的回调不能覆盖更新的意图。内核、外部协议辅助进程及 TUN 辅助进程分别记录所有权；停止和恢复针对本实例拥有的进程。恢复原配置会重新建立连接，不会复原已经断开的 TCP/TLS 会话。

**测试结果与批量测试**

混合内核的批量测试共用总并发预算，可以取消。测试请求使用各自的配置和内核上下文，不通过修改全局默认内核来生成另一份配置。

| 测试入口 | 结果含义 |
| --- | --- |
| URL 测试、批量 URL 测试 | 按下次连接将使用的配置和内核测试。 |
| TCP 测试 | 服务器端点的 TCP 可达性，与 URL 代理测试分别记录。 |
| 综合测试 | 记录本次选择的测试项目及独立报告；报告不会作为失败原因写入。 |
| 当前连接测试 | 使用已保存的实际运行配置快照，与下次连接结果分开。 |

结果记录内核及构建标识、配置指纹、生成配置摘要、测试模式、参数、作用范围、时间与状态。修改节点、相关设置或内核构建后，旧结果可以查看为历史，不能继续当作当前配置的有效结果。

排序采用有效的“下次连接 URL”结果；没有有效 URL 结果时，界面可以带 TCP 或综合测试标签显示其他结果。从 0.1 开始，“删除不可用配置”优先采用有效 URL 结果，URL 未测试时可采用同一配置和内核的有效 TCP 或综合测试连接失败结果。正在使用、另一内核的失败、取消、过期、暂不支持和内核异常均不会据此误删节点；无可删项时显示原因。

**旧配置和订阅更新**

- 旧节点缺少选核字段时按“自动”处理；原默认优先内核继续沿用。没有来源信息的旧延迟和报告保留为历史。
- 内核偏好、测试历史等本地字段不参与节点协议身份比较，也不作为分享链接中的协议参数。
- 同组内仅改名、重排或“更新前清空”的订阅更新，按完整节点配置进行唯一匹配；匹配成功时保留节点 ID、偏好、历史和流量信息。
- 重复而无法唯一匹配、或配置已经变化的节点使用自动偏好，避免把一条节点的设置套到另一条。
- 解析失败或没有有效节点时保留原分组；订阅移除了仍在连接的节点时，保留该节点可见，便于停止或后续处理。
- 部分节点解析失败时拒绝整次订阅替换，保留旧节点和元数据；普通粘贴仍可追加其中的有效节点。新协议的未知、冲突或重复 YAML 字段、非法端口/带宽/时长会给出具体错误。
- 编辑器保留长密码、元数据及原始证书文本；Hysteria2 显式空 BBR 值在克隆、保存和重载时保持。Qt 6 构建的 64 位整数不再经由 double 转换，接收窗口的 `2^53+1` 和 `qint64` 最大值已做保存及分享回导验证。

**新增协议**

| 协议 | 可用选项 |
| --- | --- |
| AnyTLS | 密码、TLS/SNI、证书验证、自定义 CA、ALPN、uTLS、空闲会话设置和客户端元数据。 |
| Snell 4/6 | 明确选择版本、PSK、用户密钥、复用及 TCP/UDP；v4 提供 HTTP/TLS 混淆，v6 提供整形模式。 |
| Hysteria2 | 保留旧字段，增加标准/保守/激进 BBR 配置、Gecko 混淆、Chrome QUIC 指纹开关及随机跳端口间隔。 |

三者按能力自动使用 sing-box，新建、导入、编辑、分享、订阅及测试入口均已接入。高级控件默认收起；仅支持 UDP 的 Snell 显示 URL 测试“不适用”，不会因此进入“移除不可用”的候选。带有扩展选项的节点使用完整 Nekoray 分享格式，避免丢失参数。`snell://` 是本项目的兼容格式，必须写明版本 4 或 6。新选项不支持交给旧外置核心时会明确说明原因。
